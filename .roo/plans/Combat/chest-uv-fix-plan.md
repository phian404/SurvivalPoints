# План: исправление UV-развёртки выступа торса (женская модель) — ЗАВЕРШЁН

## Статус

Задача решена и проверена в игре. Команда `/spdebug chest` и класс `ChestDebugCommand` удалены; `SurvivorChestTuning` превращён в хранилище констант.

## Итоговая реализация

- [`SurvivorBodyModel.java`](../../../src/main/java/com/phian404/survivalpoints/client/SurvivorBodyModel.java) — четыре сегмента `chest_seg0..3` + два капа нижней грани `chest_under0..1`.
- [`SurvivorChestTuning.java`](../../../src/main/java/com/phian404/survivalpoints/client/SurvivorChestTuning.java) — константы формы (`width=2`, `height=3`, `depth=3`, `offsetY=3`, `offsetZ=0.5`, `offsetXL=-2`, `offsetXR=2`, `tiltL=tiltR=-0.5`).
- [`ModEntityRenderers.java`](../../../src/main/java/com/phian404/survivalpoints/client/ModEntityRenderers.java) — модели строятся один раз при регистрации рендерера; пересборка по `revision()` удалена.

## Что было сделано

1. **Непрерывный UV передней грани.** `texOffs` сдвигается на `width` за сегмент (`u = 20 + i*width - depth`), поэтому грани `NORTH` четырёх кубов читают ровно переднюю грань торса (`u 20..28`) — стыки невидимы, цвет совпадает с торсом на любом скине.

2. **Верхняя грань отключена.** `DOWN` (визуально верх) не рисуется: его UV попадает в строку воротника и давал горизонтальные полосы.

3. **Нижняя грань — отдельные капы.** `CubeListBuilder` в 1.20.1 не умеет задавать отдельный UV одной грани внутри куба (`texOffs` общий, кастомный полигон недоступен). Поэтому нижняя грань рисуется двумя кубами `chest_under0..1` с единственной гранью `UP` и своим `texOffs`. При `depth=3.0` (целое) слоты читают ровно `u 20..24`/`24..28`, `v 24..27` — целые границы, без растяжения.

4. **Мерцание боковых граней.** Внутренние боковые грани на стыках сегментов удалены (обращены внутрь детали, невидимы). Открыты только внешние торцы `seg0.WEST`/`seg3.EAST`. Внешние сегменты сужены до `width-0.1` и сдвинуты внутрь на 0.05, чтобы боковины (`x=±3.9`) не касались торса (`x=±4`) — стыки остаются встык без перекрытия и щели.

5. **`texScale=0` отклонён** — приводит к делению на ноль при расчёте UV в `ModelPart.Polygon`.

6. **Зачистка.** Удалён `ChestDebugCommand.java` (команда `/spdebug chest`), из `SurvivorChestTuning` убраны сеттеры, `revision`, `reset`, `MIN/MAX`-коридоры. Из `ModEntityRenderers` убрана пересборка по `revision()`. Обновлены javadoc и `AI_CONTEXT.md`.

## Проверка в игре (пройдена)

1. Женский NPC без нагрудника: полос на груди нет, цвет выступа совпадает с торсом.
2. Нижняя грань закрыта капами, цвет совпадает с торсом, без растяжения и смещения.
3. Мерцание боковых граней на стыках пар и в месте контакта с телом отсутствует.
4. Смена скина — `Farm_female_0`, `Medic_female_0`, `Leader_Martha_Hil_female_0`: цвет выступа совпадает с торсом на каждом.
5. Мужской NPC: выступа нет.
6. Нагрудник на женском NPC: выступ скрывается.
