# План: анимация тетивы арбалета стража

1. Добавить небольшой рендер тонкой 3D-тетивы в существующий `CustomWeaponLayer`, без новых классов, ресурсов и отдельной модели.
2. Использовать уже синхронизированный прогресс заряда для плавной оттяжки; отображать анимацию только во время натяжения.
3. Подогнать положение тетивы к ванильному арбалету, не меняя механику стрельбы и существующую анимацию рук.
4. Проверить сборку командой `gradlew.bat compileJava`, затем визуально проверить результат в игре.
