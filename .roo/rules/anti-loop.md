# Anti-Loop Rules

## General Rules

1. Do not repeat the same tool call, command, or action without a clear reason.
2. Before retrying, inspect the previous result and identify what will be different.
3. If two consecutive attempts produce the same error or no progress, STOP and reassess the approach.
4. Never repeat a failed action without changing the relevant input or strategy.
5. If blocked, summarize what was tried, what failed, and the next recommended step.
6. Preserve successful changes when stopping. Never claim completion without verification.
