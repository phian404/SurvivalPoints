# Инструкции по работе с Blockbench MCP

У тебя есть доступ к инструментам Blockbench через MCP-сервер. Перед началом любой работы с 3D-моделью убедись, что соединение активно, вызвав инструмент проверки (например, `blockbench.hello` или аналогичный, если он доступен).

## Основные принципы
1. **Всегда проверяй соединение**: Если инструменты Blockbench возвращают ошибку подключения, напомни пользователю, что нужно открыть Blockbench и загрузить плагин MCP.
2. **Используй только доступные инструменты**: Не пытайся выполнить действия, которых нет в списке инструментов MCP (например, не пиши скрипты для Blockbench напрямую, если для этого нет инструмента).
3. **Сначала осмотрись**: Перед созданием или изменением элементов запроси информацию о текущем проекте (`get_project_info` или аналогичный инструмент), чтобы понять его структуру.
4. **Безопасность**: Помни, что инструменты MCP могут изменять проект. Если действие необратимо, предупреди пользователя или предложи сделать бэкап.

## Типичные задачи
- Создание кубов: используй инструмент `add_cube` (или его аналог в вашей версии плагина).
- Просмотр элементов: используй `list_elements`.
- Удаление: используй `remove_element`.

Если ты не уверен, какой инструмент использовать, сначала запроси список доступных инструментов MCP у пользователя или проверь документацию плагина.
