=== SURVIVALPOINTS GUARDIAN AI DEVELOPMENT LOG ===

1. RANGED ATTACK & ROTATION
- Implemented smooth interpolation for YRot (delta * 0.2F) to prevent jittering.
- Rotation is handled at the start of tick() to ensure facing the target during retreat.

2. COMBAT STATE SYSTEM
- Used Byte in SynchedEntityData (DATA_COMBAT_STATE) to toggle between RANGED and MELEE.
- RANGED -> MELEE: distance < 3.0D
- MELEE -> RANGED: distance > 7.0D

3. PANIC & RETREAT LOGIC
- Trigger: distance < 6.0D && distance > 2.0D.
- Behavior: Search for nearest BaseGuardianEntity within 32 blocks.
- If ally found: Move towards ally.
- If no ally: Move away from target.
- Method: setDeltaMovement (direct physical push).

4. HELP SYSTEM (Call for Help)
- Triggered during panic state.
- Logic: Find all BaseGuardianEntity in 32 blocks, set their target to the attacker.
- Cooldown: 200 ticks (approx 10s) via helpScreamCooldown to prevent spam.
- Chat messages: " Помогите мне!\ (caller), \Уже бегу!\ (allies with no current target).

5. KNOWN ISSUES & RECOMMENDATIONS
- Performance: getEntitiesOfClass is called during panic. Recommended optimization: run check every 5-10 ticks instead of every tick.
- Movement: setDeltaMovement can be overridden by standard PathfinderMob navigation. If movement is inconsistent, consider using custom Navigation goal.
- Sync: Ensure BaseGuardianEntity is updated to use Byte for combat state to avoid Enum wrapper crashes.
